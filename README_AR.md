# سيرفر رشد السحابي — نسخة Render

## محتويات هذه النسخة
- Flask API.
- PostgreSQL بدلاً من SQLite حتى تكون قاعدة البيانات مستقلة عن ملفات التطبيق.
- فحص الحالة: `GET /api/health`.
- إنشاء حساب: `POST /api/register`.
- تسجيل دخول مستخدم: `POST /api/login`.
- تسجيل دخول المدير: `POST /api/admin/login`.
- رمز دخول موقّع صالح لمدة 7 أيام، والتحقق عبر `GET /api/me`.

## النشر على Render
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو مجلد Server في المستودع.
2. في Render اختر New > Blueprint ثم اربط المستودع الذي يحتوي `render.yaml`.
3. سيطلب Render قيمة `ADMIN_PASSWORD`. أدخل كلمة مرور جديدة وفريدة، ولا تضعها في GitHub أو ترسلها في المحادثات.
4. تأكد من إعداد `ADMIN_USERNAME` بالقيمة `sasha th34**`.
5. ابدأ النشر وانتظر نجاح Build وDeploy.
6. اختبر `https://YOUR-SERVICE.onrender.com/api/health`.

## مهم
- خطة Render المجانية قد توقف خدمة الويب عند الخمول، وقاعدة البيانات المجانية لها مدة صلاحية وحدود. للاستخدام الدائم وبيانات الأعضاء الحقيقية اختر خطة مدفوعة وراجع حدود Render الحالية.
- لا تضع أسراراً أو كلمات مرور داخل المستودع.
- هذه نسخة تأسيسية: لا تشمل OTP/WhatsApp، أو واجهة إدارة كاملة، أو رفع الفيديوهات، أو الإشراف، أو نظام الصلاحيات التفصيلي. لا تعتبرها جاهزة للإطلاق العام قبل إضافة rate limiting ونسخ احتياطي ومراجعة أمنية.
- قاعدة PostgreSQL جديدة؛ لم يتم ترحيل بيانات SQLite القديمة تلقائياً.
